# Нить поколений

Платформа для сообщества, которое записывает нематериальное культурное наследие — обряды, песни, ремёсла, устные истории — пока живы те, кто их помнит.

Три модуля, больше ничего: **Архив** (материалы с именем носителя), **Люди** (кто помнит и кто может помочь), **Дела** (маленькие задачи со сроком).

Требования — в [ТЗ_сообщество_наследие.md](ТЗ_сообщество_наследие.md), правила работы над кодом — в [CLAUDE.md](CLAUDE.md).

## Стек

- **SvelteKit 2 / Svelte 5**, SSR — страница читается до загрузки JS, бандл маленький.
- **Supabase** — Postgres, хранилище медиа, вход по ссылке на почту, права через RLS.
- **Cloudflare Pages** — бесплатный хостинг с CDN. В проекте стоит `adapter-auto`: на хостинге он сам подставит `adapter-cloudflare`, а локально не тянет за собой эмуляцию workerd, которая на Windows роняет dev-сервер ошибкой `write EOF`.

## Как поднять локально

Нужен Node.js 20+ (проверено на 24.21).

```bash
npm install
cp .env.example .env    # и подставить ключи из панели Supabase
npm run dev
```

Открыть http://localhost:5173

Для владельца проекта есть файл **«Открыть сайт.bat»** — в корне проекта и на рабочем столе. Двойной клик запускает сервер и сам открывает браузер; сайт работает, пока открыто чёрное окно. Закрыли окно — сайт погас.

Если `npm install` напишет `install scripts not yet covered by allowScripts`, выполните `npm install-scripts approve esbuild` — без этого esbuild не поставит свой бинарник.

Приложение поднимается и с незаполненным `.env`: страницы отдаются, ленты показывают «пока пусто» и сообщение об ошибке загрузки вместо падения. Так же оно поведёт себя, если Supabase окажется недоступен у человека в кишлаке.

## Как накатить базу

1. Создать проект на [supabase.com](https://supabase.com) — регион Frankfurt (ближайший к Таджикистану из бесплатных).
2. В панели: **SQL Editor** → выполнить [supabase/migrations/0001_init.sql](supabase/migrations/0001_init.sql).
3. Туда же — [supabase/seed.sql](supabase/seed.sql), если нужны примеры. Перед реальным запуском их стоит удалить: `delete from records; delete from people; delete from tasks;`
4. **Project Settings → API** → скопировать `Project URL` и `anon public` ключ в `.env`.
5. **Authentication → URL Configuration** → в `Redirect URLs` добавить `http://localhost:5173/auth/callback` и адрес продакшена.

Альтернатива через CLI: `supabase link --project-ref <ref>` и `supabase db push`.

Проверить, что всё сошлось: `npm run db:check`. Скрипт скажет, какие таблицы на месте, доступно ли хранилище и — главное — отклоняется ли анонимная запись. Если аноним смог добавить запись, значит RLS не включился и материалы может испортить любой прохожий.

## Как устроен доступ

- **Смотреть может любой**, без регистрации: архив открыт, иначе он не работает как приглашение.
- **Добавлять** записи, людей и дела может только вошедший — вход по одноразовой ссылке на почту, без пароля.
- **Чужое дело можно двигать, но не переписывать.** Любой вошедший может откликнуться на задачу и отметить её выполненной — иначе нельзя завершить дело, к которому подключился. А название, описание и срок остаются за автором: это стережёт триггер `guard_task_fields` в базе, а не только интерфейс.
- **Носители традиций не регистрируются.** Носитель — это не аккаунт, а имя рядом с материалом (`records.carrier_name`). Анкету и запись за пожилого человека заводит помощник. Это снимает главный барьер для аудитории, которая не пользуется интернетом.

## Языки

Русский и таджикский. Все строки — в [src/lib/i18n/ru.json](src/lib/i18n/ru.json) и [src/lib/i18n/tg.json](src/lib/i18n/tg.json), переключатель в шапке пишет выбор в cookie.

> **Таджикские переводы не вычитаны носителем языка.** Они сделаны при разработке и годятся для проверки интерфейса, но перед тем, как звать людей, их нужно показать тому, для кого таджикский родной. Если ключа в `tg.json` нет, интерфейс молча покажет русский — сломанного текста человек не увидит.

Добавить язык: новый `xx.json`, добавить код в `LANGS` в [src/lib/i18n/index.ts](src/lib/i18n/index.ts) и поправить переключатель в шапке (сейчас он рассчитан ровно на два языка).

## Интерфейс

Оформление рассчитано сразу на две аудитории, и это не компромисс, а условие задачи: молодёжь нужно зацепить, носителям традиций нужно не мешать.

- **Палитра голубая с белым**: небесно-голубой основным, бирюза вторым, белые карточки на очень светлом холодном фоне. Типы наследия различаются оттенками той же гаммы — от голубого к бирюзовому.
- **Залитые кнопки используют `--accent-strong`**, а не `--accent`: белый текст на светлом голубом даёт контраст 4.1 при норме 4.5. Меняя голубой, пересчитайте контраст, иначе кнопки станут нечитаемыми для тех, ради кого всё затевалось.
- **Узоры на карточках** — шерози (плетёный зигзаг) полосой сверху и ромб с рогами архара, мотив джурабов Бадахшана, в нижнем углу при непрозрачности 9%. Оба заданы CSS-маской, а не картинкой: форма в data-URI, цвет берётся из `--type`, поэтому узор красится в цвет своего типа наследия. За текстом узора нет намеренно — читать здесь главное.
- **Тёмная тема** включается по настройке системы (`prefers-color-scheme`), отдельной кнопки нет — лишний переключатель в шапке ничего не даёт.
- **Нижняя панель навигации на телефоне**, как в привычных приложениях: цели под большим пальцем, 56px высотой. На экранах от 760px она уезжает в шапку.
- **Крупная типографика** с `clamp()`: заголовки растут вместе с экраном, базовый текст не мельче 17px.
- **Шрифты**: [Onest](https://fonts.google.com/specimen/Onest) для текста, [Unbounded](https://fonts.google.com/specimen/Unbounded) для крупных заголовков и цифр прогресса. Оба обязательно с подмножеством `cyrillic-ext` — там живут таджикские **ӣ ӯ ҳ қ ғ ҷ**; без него таджикская версия распалась бы на два разных шрифта. Цена — около 93 КБ на первый заход, дальше из кэша браузера; `display=swap` показывает текст системным шрифтом сразу, не дожидаясь загрузки. Если трафик окажется важнее вида, дешевле всего убрать Unbounded (34 КБ из 93) — заголовки перейдут на Onest без правок разметки.
- **Анимации короткие** (0.15–0.3 с) и полностью отключаются при `prefers-reduced-motion`. На слабом телефоне долгая анимация читается как зависание.
- **Кликабельное — не меньше 44–48px**, фокус виден, скрытых жестов и ховер-меню нет: всё, что можно нажать, видно сразу.
- `color-mix` и `backdrop-filter` подстрахованы сплошным цветом — на старых Android-браузерах панели не станут прозрачными.

## Знак

Чорхона — потолок памирского дома: четыре квадратные рамы, каждая повёрнута на 45°, в середине руз (отверстие для света), по краю зигзаг шерози. Залит синим градиентом — цвет неба, которое видно в руз. Лежит в [src/lib/components/Logo.svelte](src/lib/components/Logo.svelte).

- **Пропорции не произвольны.** Повёрнутая на 45° рама вписывается в предыдущую, только если меньше её ровно в √2 раза — отсюда ряд 11.2 → 7.92 → 5.6 → 3.96. Меняя размеры, пересчитайте, иначе кладка «поедет» и памирец это заметит.
- **Иконка вкладки нарисована отдельно** ([static/favicon.svg](static/favicon.svg)): три венца вместо четырёх и без шерози. На 16 пикселях полный рисунок слипается в пятно.
- **Орнамент живёт только в знаке.** Обложка главной намеренно без узора: два разных орнамента на одной странице спорят друг с другом.

Если однажды сюда попадёт чужой снимок, под плитками должна вернуться строка с именем автора и лицензией: без неё использование незаконно.

## Решения, которые лучше не отменять не подумав

- **Имя носителя обязательно** (`not null` в базе) и стоит на карточке, а не только внутри. Материал без имени человека — это обезличивание, ради чего архив и затевался.
- **Срок у задачи обязателен.** Дело без срока превращается в абстрактную миссию, на которую никто не откликается.
- **Счётчики на главной — часть механики**, а не украшение: человеку, которого позвали «сохранять культуру», нужно сразу увидеть, что дело уже идёт.
- **Фильтры — ссылки, не JS-состояние**: отфильтрованной лентой делятся в Telegram, и она должна открываться у того, кому её прислали.
- **Изображения сжимаются в браузере** перед отправкой: фото с телефона на 6 МБ по мобильному интернету не доходит.
- **Медиа с `preload="none"`, картинки ленивые** — трафик здесь стоит денег.
- **При обрыве связи `supabaseFetch` возвращает ответ 400, а не бросает исключение** ([src/lib/supabase.ts](src/lib/supabase.ts)). На исключении и на пятисотых кодах supabase-js уходит в серию повторов с нарастающими паузами — восемь попыток превращают мгновенный отказ в семь секунд ожидания. Замерено: страница отдавалась 7,06 с, стала 0,04 с. Если менять код ответа — сначала замерьте `curl -w "%{time_total}"` при выключенной базе.
- **Внутреннего чата нет** — в карточке человека телефон или Telegram. Люди должны созваниваться и встречаться, платформа только помогает найти друг друга.

## Деплой

Cloudflare Pages → подключить репозиторий, команда сборки `npm run build`, каталог `.svelte-kit/cloudflare` (его создаёт `adapter-auto`, определив платформу — локально он этого сделать не может и честно пишет «Could not detect a supported production environment»). Переменные `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`, `PUBLIC_SITE_URL` — в настройках проекта. После первого деплоя добавить `https://<домен>/auth/callback` в Redirect URLs в Supabase.
